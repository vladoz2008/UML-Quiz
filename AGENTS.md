# AGENTS.md

## Cursor Cloud specific instructions

- Это статическое веб-приложение (HTML + CSS + JS) без зависимостей, сборки и бэкенда.
- Для запуска достаточно статического HTTP-сервера: `python3 -m http.server 8080` из корня репозитория.
- Приложение доступно по адресу `http://localhost:8080`.
- Тестов, линтера и системы сборки нет — проверка только ручная через браузер.
- Данные квиза хранятся в `localStorage` (счётчик прохождений).
